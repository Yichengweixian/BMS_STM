当前实际运行链路

启动与初始化 → OLED 显示 BMS_EX → USART1 输出启动信息 → ADBMS1818 采样一次并打印 → 空 while(1)。串口接收中断提供回显。ADC 与 TIM 已配置，但没有启动采集/PWM；按键、PI、自动均衡尚未接入主程序。

三套材料需要分清

  • 课程目标：docs/course中的PPT与任务2步骤，包含基础控制、交互和后续 TinyML。
  • 可编辑模板：BMS_EXv1.1/BMS_EX，使用 C、STM32 HAL/CMSIS、Keil MDK；目前尚未实现完整恒流系统。
  • 现成采集测试工具：firmware/prebuilt/BMS_Appli.hex + tools/host/BMS上位机d.zip + docs/manuals中的上位机手册。HEX 与模板产物不同，上位机压缩包仅有 EXE，未提供其源码。手册所述完整控制能力不能直接归到模板源码。

进入下一阶段前的核对项

  1. main.c 的 ADC1 已改 CH1、2倍过采样右移1，TIM1 ARR=2000、RCR=1，旧 README/讲义部分描述过时；ADC2 的 .ioc 与 C 配置不一致。
  2. pi.c 与 pi.h 的类型和接口不一致；当前主程序未使用 PI，pi.c 未加入 Keil targets。先统一实现，再接 ADC 完成回调。
  3. 讲义写 INA199A2 增益50；TI 官方规格 INA199x2 是100。应核对实物型号、前端电路和实测灵敏度，不能直接照抄电流系数。TI 器件资料
  4. 现成上位机的 bms 命令协议、讲义的 set 文本命令和当前模板的原样回显是不同完成状态，需要明确对接目标。
  5. 本目录没有 FSBL 工程/独立镜像；Release 启动依赖板上已有 FSBL。Debug 正常不代表断电上电能运行。
  6. 现有 Debug 构建产物早于当前 main.c，Release 产物更旧；应先重新构建再确定代码基线。Debug map 中堆在 HyperRAM，而 Release 堆在内部 SRAM。

建议推进顺序

  1. 整理基线：选定当前 Keil 工程，统一配置与 PI 接口，重新构建并验证串口/OLED。
  2. 完成任务1：定时读取三节电压/电流/温度，校验和标定，并以1 Hz显示与上报。
  3. 完成任务2：验证互补 PWM 波形与驱动时序，记录开环扫描，在已完成电流ADC标定与停止验证的基础上，接入闭环、限幅与换向逻辑。
  4. 完成任务3：STOP/充电/放电模式、继电器互锁、按键设定、OLED刷新、串口协议。
  5. 采集带时间戳的真实数据，生成SOC标签、训练/评估/量化模型，再加入端侧推理。当前目录没有数据集、模型或训练代码。
