# 预编译 HEX 电流公式与受限扫描可行性核对

2026-10-31；范围：static。没有访问串口、烧录、切换继电器或启用 PWM。当前 g03-disabled-r1 不变。

用户提出从较大占空比向较小占空比扫描、越限停止并记录。这是可实现的实验策略；实际执行前需要把真实电流采样与本地停机接通。正式精度标定与探索调试应区分，不能把所有软件推进都等同于必须先完成正式硬件验收。

## 实际阻塞点

- 当前 G03 接的是合成输入，实际 PWM/继电器使能接口尚不存在；不能把已经通过的合成故障测试当作真实电流保护。
- 当前 G01 MCU 电流原码约 1008，AFE 电流采样电压标称约 0.89984 V。课件 MCU 模型在 0.9 V 零点下预期约 2048 码。ADC 参考、输入路径、配置和自校准的差异尚未定位；不能仅把 1008 强制设为零点就宣布斜率正确，也不能认定两路一定是同一节点。
- 串口遥测为约 500 ms 周期，不能用主机看到超限才发 STOP 作为唯一过流保护。必须由 MCU 的真实 ADC 路径判定、立即撤销输出并锁存，主机负责扫点请求和记录。
- 已知 33Ω/25W 负载不直接限定电池侧和开关管峰值电流。驱动极性/死区/触点及实际电气停止未测；不能由寄存器读回或 HEX 替代。

## 课件可以先复用什么

任务2实验步骤给出 `I=(code-code_zero)*1.8/4095/0.75`，电流增益依据为 50×0.015=0.75 V/A。可作为标称软件模型，必须带来源与“未独立标定”标记。不能把未知实物增益、限流值填为示范数值。

同份实验步骤把 TEST_DUTY=0.90f 作为较小放电电流端，减小该定义下的 D 会增强放电。因此用户的大 D 向小 D 扫描是逐步增加放电强度；遇到超限必须停止，不能继续向小 D 调。此结论绑定课件的上管占空比/极性定义，不能泛化为任何 PWM 的“大占空比更安全”，0.90 也不是本板已验证的安全启动值。

PPT 文字写 INA199A2/50倍，嵌图标 INA199A1DCKR；TI 规格 x1=50、x2=100 V/V。资料存在标注冲突，HEX 的软件系数有帮助，但不能证明实装器件型号。

## 从 HEX 恢复的实际算术

来源：firmware/prebuilt/BMS_Appli.hex；SHA256 `dd44fae11ed542ad6bcee45b35a13e93bd6632481b7d29662afda8ac7856be7f`。Intel HEX 校验和及重叠一致性检查通过；不是当前源码构建产物。

在 0x70102fc6 起的运算路径，r6 输入原码转换为浮点，乘 LSB，VFNMS 扣除独立零点，然后乘双精度增益。结合 I_ZERO_MCU 字符串和 AWD 的逆向换算，恢复为：

```
K = 1.3266666730244954 A/V
LSB_MCU = 0.0004395604191813618 V/code  # float32(1.8/4095)
I_MCU ≈ (code * LSB_MCU - zero_MCU_V) * K
I_AFE ≈ (raw * float32(0.0001) - zero_AFE_V) * K
```

MCU 零点运行地址 0x34000058，AFE 零点运行地址 0x3400005c。AFE 换算位于 0x701050ec..0x70105144，小于约 0.0008 A 的绝对值被置零显示。MCU 某些控制模式分支使用相反符号（VFMS）；上式对应普通测流分支，不能把内部控制误差符号等同于实物充放电方向。

K 常量位于 0x701032d8、0x70105238、0x70105d10、0x701068a8，四处完全一致；约比 1/0.75 小 0.5%。这只能证明软件系数，不能推断作者做过何种实物标定。

0x70105c1a..0x70105cc0 将电流限值反算 ADC 窗口：

```
high/low = clamp_to_0_4095((zero_MCU_V ± limit_A/K) / LSB_MCU)
```

最终浮点转无符号整数使用截断。二进制含 `[AWD]` 提示：阈值超出 I 通道量程时被钳位，相应保护无效。因此不能复制钳位后还继续运行的行为；移植时应拒绝量程外限值。ADC 看门狗配置调用和常量可定位，但本次未完整恢复中断关断路径，也未证明其电气响应时间。

HEX 含 ADC1/ADC2 offset calibration 和两个 I_ZERO 校零相关代码/字符串；当前应用未调用 HAL_ADCEx_Calibration_Start。两者是待比较的配置差异，尚不能认定它就是约两倍原码差异的原因。ADC 内部自校准可以由固件执行，不等于用参考电流对整条模拟链做斜率标定。

## 不依赖用户探头的下一步

1. 保持禁能，对比预编译固件与当前 ADC 初始化、自校准、参考电压选择、采样通道和缩放；补充寄存器诊断，用同一静态工况比较两路。
2. 将恢复公式做成明确标记的标称换算候选，验证原码、零点和饱和检查；保留原码，不覆盖已有未标定数据。
3. 把 G03 合成保护接入真实 ADC 的禁能运行版本，并补 ADC 看门狗阈值合法性、本地停机、最长运行期限、失联锁存；先禁能验证。
4. 扫描器只请求固定点，MCU 限制步长/期限并记录触发前后数据；出现故障终止整个扫描，不自动重试。实际功率试验另依赖驱动/停止路径及本次能量限值的证据。
