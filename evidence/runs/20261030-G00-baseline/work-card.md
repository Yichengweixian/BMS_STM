## 配置冲突与处理

| 项目 | 实际发现 | 本轮处理 |
|---|---|---|
| ADC2 | ioc 为1转换/通道0，源码为3转换/通道0、14、11；过采样字段亦不同 | 冻结当前源码为实际构建基线，G01前对齐；不直接重新生成覆盖源码 |
| PI | pi.c 使用 PI_Controller_t，pi.h 使用 PI_t；pi.c 未加入两个 target | 记录为未接入旧实现，G04前统一接口 |
| Keil 下载器 | 工程保存旧序列号，与实物16004A002933353739303541不同 | 本轮使用已验证的 CubeProgrammer 显式序列号；Keil直接下载未验证 |
| Debug heap | MAP 在外部 HyperRAM 0x90000000 | 保留原始基线，Debug运行需单独实测，不能等同Release |
| 板型资料 | 根目录出现 STM32F4 原理图，当前工程/实测MCU是STM32N647 | 不将F4图作为本板接线/电平依据 |
| 安全默认态 | main.c 将 PG5/PB5 继电器输出写低，未发现 ADC/TIM Start 调用 | 只能证明源码行为；继电器有效极性、实物输出/默认禁能未验证 |
| 停止设计 | UART为回显，没有业务 STOP/失联/互锁状态机 | 不允许由本轮基础启动结果推导功率安全结论 |
