# G01 电压优先：采集与软件收尾

按用户要求，电流和温度实物标定暂缓，现阶段只具备电压测量条件。本轮新增上位机电压统计、候选拟合与独立验证工具，未修改或烧录固件，未改变 BOOT、负载或功率控制。

## 实板采集

首次 COM9 监听 65 秒无数据，保留在 capture。用户确认就绪后，capture-retry 记录 90 秒，解析出 1603 条记录、177 个完整九通道组。九通道已解析记录原码全部有效；起始解析错误和末尾 73 字节残片共计两项错误，首尾两个不完整组保留，未充作完整组。完整序列内未见组序号缺失或重复；采样间隔中位数 500 ms。

电芯 cell1/cell7/cell13 按原码标称比例换算均值分别约 3.8910/3.8910/3.8916 V。这是未校准名义值，不能作为已验证精度。

## 万用表参考

无负载，OLED 在上、电池在下时，左 A 3.895 V（用户记时 14:05:05）、中 B 3.894 V（14:06:09）、右 C 3.894 V（14:07:00）。用户随后确认万用表读数基本未变，因此这组数据可作为约 3.9 V 工作点的初步数值对照，时间差不作为继续软件工作的阻碍。

电脑采集约 13:52～13:53，与手工记时未对齐；未取得量化漂移上限，也未确认 A/B/C 与 AFE cell1/7/13 的对应关系。两组读数整体相差约数 mV，不能据此给各通道写入偏置或宣布精度合格。三节相近电压不算同一通道的三个标定点。

## 软件与验证

- scripts/g01/voltage_calibration.py：核验采集文件哈希、帧校验与原码语义；统计各通道有效性、均值及波动；按通道生成线性校准候选。
- 拟合要求每通道至少三个不同参考电压，另留独立验证点；拒绝无效、陈旧、重复、缺失、时间断续或重复使用的样本窗口，并要求映射和参考条件证据。
- 精度判定需要已冻结容差和有依据的比较不确定度。仿真不产生实物合格结论；工具不写固件或自动应用系数。
- 16 项 Python 测试通过；生产 C 故障注入及 36 条合成串口记录端到端回放通过。软件结果见 software-checks/result.json；实板数据与仿真数据分开保存。
- 使用说明：instructions/specs/G01-voltage-tools.md；取点模板：scripts/g01/voltage-points.template.json。
