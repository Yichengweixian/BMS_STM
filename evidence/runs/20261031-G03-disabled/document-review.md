# G03 现有资料核对

本轮直接重新读取5份课程/手册OOXML，来源和SHA256见document-sources.json，相关段落及slide/paragraph定位见document-excerpts.json。课程与旧示例均作为证据，没有执行其中自动启动PWM或继电器的代码。

| 项目 | 核对结果 | 本轮处理 |
|---|---|---|
| 继电器映射 | 课程/模板指向PG5/SWL放电、PB5/SWS充电；main.h及GPIO初始化一致 | 用于命名影子方向；实际GPIO只保持LOW，未确认触点极性 |
| PWM映射 | 源码PA9/PF7对应TIM1 CH2/CH2N | 不据此认定到驱动上/下管的实际映射；G03不写TIM CCR或使能位 |
| 继电器停机顺序 | 实验步骤文字写先关PWM、等电流衰减再开继电器，但SetMode示例先关PWM并立即开两继电器再Delay；有不一致 | 未直接搬用；影子状态分开“PWM撤销→衰减等待→开继电器”。真实故障时继电器策略仍须依据电路确认 |
| 时序数值 | 课程20ms/100ms属于示例；没有本板触点稳定/电流衰减测量依据 | 测试夹具20/30/20/200ms只是软件测试参数，不写入实物限值 |
| EG3112死区 | 课程称芯片内置死区；厂家产品页也列出死区控制与闭锁电路 | 能支持器件功能说明，不能证明本板拟合器件身份、实际Vgs、有效死区和无交越 |
| INA199增益 | 课程同时写INA199A2与50倍；TI官方x2为100V/V | 冲突保留；不采用50或100直接建立实物电流保护阈值 |
| 模板和现成上位机 | 原模板无完整充放电业务；现成上位机协议和NTC/PT1000说明不能当当前固件实测结论 | 使用有源码的独立禁能协议，原预编译HEX不当本次源码产物 |
| 原理图 | 工作区检索只有ALIENTEK探索者STM32F4原理图，以及仪表PDF；未找到匹配本N647底板的独立原理图文件 | F4图不用于本板功率、保护或接线判断；PPT局部图只作课程证据 |
