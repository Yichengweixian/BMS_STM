## 1. 目标与现有条件

目标是取得第一组真实的“接通—电流响应—断开恢复”数据，再决定如何进入 PWM 固定占空比实验。

沿用用户最近确认的接线：三节真实电池、放电端接原有 33Ω/25W 标称负载、充电端开路。硬件事实以 [hardware-profile.json](specs/hardware-profile.json) 为唯一入口；本文数值是对应工况的估算，不新增实物额定值。

用户不能接示波器探头、测量细小引脚或配合硬件标定。本方案不要求这些操作，也不要求把电阻另接到电池端、绕过板上通路。

当前板上固件为 `g03-adc-r4`，仍保持禁能。既有真实 ADC 诊断和合成状态机测试，不能直接执行本方案。

## 2. 为什么先测试继电器

老师的实验步骤写明：PG5 控制放电继电器 SWL，PB5 控制充电继电器 SWS，高电平吸合；示例先闭合放电继电器、等待 100ms，然后才启动 PWM。本方案只测试前面的继电器阶段。

课件功率拓扑显示可能存在以下被动放电通路：

```text
电池 → 电感 → 半桥中点 → 上管体二极管 → 母线/放电继电器 → 33Ω负载
```

这是结合课件拓扑与继电器说明提出的假设，不是已确认的实板完整接线。第一次测试的目的之一就是观察这条通路是否存在。没有电流响应时，不能据此自动启动 PWM。

本次两个 PWM 引脚继续保持当前 LOW 状态，TIM1、MOE、CCER 均保持关闭，不进行 MOS 管互补切换。因此不把完整 PWM 波形、死区或电流精度标定作为这一步的统一前置条件。

## 3. 第一轮拟定动作

| 项目 | 拟定行为 |
|---|---|
| PWM | 两个引脚持续 LOW；不启动 TIM1 或互补输出 |
| 充电继电器 PB5 | 全程 LOW |
| 放电继电器 PG5 | 显式单次请求后置高，最多 100ms 后由 MCU 本地撤销 |
| 执行次数 | 第一轮只执行一次，不循环、不自动重试 |
| 控制方式 | 不运行 PI，不扫占空比 |
| 主记录 | AFE GPIO1 电流原码、三路电芯原码、采样时间与状态 |
| 辅助记录 | MCU 电流原码；标称电流估计单独标记 |
| 结束状态 | 两继电器 LOW、PWM禁能、结果锁存、必须重新显式请求才能再次执行 |

100ms 指 **GPIO 线圈控制命令的最长高电平时间**，不是已测得的触点实际导通时间。吸合、释放、触点弹跳和电气停止时延仍需从后续观察中区分；软件计时不能冒充独立硬件关断保证。

按电池组约 11.7V、33Ω 标称电阻估算，忽略通路压降时：

```text
I ≈ 11.7 / 33 ≈ 0.355 A
P ≈ 11.7² / 33 ≈ 4.15 W
100ms 对应的负载稳态能量约 0.42 J
```

考虑二极管压降，预期电流可能约 0.3～0.35A。这些是课件拓扑成立时的稳态量级，不是保护阈值，不能约束接触瞬间的电容电流，也不能证明实板没有其他供能路径。

## 4. 我方需要补齐的最小实现

1. **独立单次入口。** 只允许上述继电器动作；与 G02、合成 G03、真实 ADC 扫描互斥，期间不能开启 PWM、换向或修改期限。重复请求不能再吸合或延长期限。
2. **MCU 本地截止与退出。** 100ms 到期由本地定时路径撤销 PG5，不等待串口 STOP；显式停止、采样无效/过期、异常退出时同样撤销并锁存。启动和复位默认两继电器 LOW。
3. **专用真实采集。** 当前 G01 约 500ms 周期会漏掉短事件，必须改为本次专用的同步采集和缓存，记录闭合前、闭合中、撤销后的数据。先在禁能状态测清该采集流程的时长，确保窗口内能够取得有效数据。
4. **采集与控制分离。** SPI/AFE转换在主循环完成，向本地定时保护发布带有效性和时间戳的快照；不得在中断中阻塞等待 SPI。采样错误、PEC错误、超时、饱和不能输出为有效零电流。
5. **完整保留记录。** 保存命令时间、GPIO状态、采样起止时间、原码、有效标志、停止原因及固件身份；先缓存再上传，避免串口发送拖延采集和停止。

AFE 电流通道可先用于观察真实响应。MCU 的 1008／2048 差异不再阻塞这一步，但也不能把 HEX 系数、静态归零或 AFE 标称换算说成已验证的绝对电流保护。原禁能测试的 50mA 窗口不直接移作本次功率阈值。

## 5. 执行与判读顺序

1. 完成上述实现及相关离线/禁能验证，冻结本次版本、采样窗口、基线比较规则、有效性判据和退出条件。未做完之前不发继电器动作。
2. 核对接线仍为本方案工况，保存真实电芯与 AFE 静态基线。
3. 执行一次 PG5 脉冲，持续记录；到期或异常立即撤销命令。
4. 继续采集撤销后的恢复过程，再输出记录。
5. 根据以下结果决定下一项工作，不自动进入 PWM 实验。

| 观察结果 | 本轮结论与后续 |
|---|---|
| 接通时AFE原码出现清晰变化，撤销后回到预先定义的基线范围 | 支持存在可控放电响应；保留方向、时间和量级，之后再讨论重复验证 |
| 没有可辨认响应 | 结果不确定；检查继电器、通路或观测覆盖，不直接判板子损坏，也不自动加PWM |
| 窗口内没有有效采样 | 本轮观测不足，不能说“没有电流” |
| 采样错误、过期、饱和或异常电芯读数 | 中止并锁存，保存原始记录 |
| 撤销命令后读数不恢复 | 不启动下一次；软件LOW不能冒充物理断开，需按预先明确的电池侧断开方法终止供能 |

基线容差、数据过期时间、电芯退出值和撤销后的观察期限属于执行前待冻结项；本文不填写未经核对的数值。应针对这一次动作补齐，不能借此重新要求用户完成整套探头测量和精度标定。

## 6. 交付与后续边界

首次运行交付一份独立记录：原始串口/采样数据、接通与撤销事件、AFE与电芯时间曲线、停止原因，以及“观察到响应／无响应／数据不足”的结论。尚未运行时不建立通过结果。

若观察到可解释的真实响应，再决定重复测试及受限 PWM 单点实验；若未观察到，围绕这次记录查具体通路，不自动延时或提高功率。

本方案能争取第一组真实放电通路数据，尚不构成完整 G03 PWM 开环、精确电流标定、微秒级关断、充电功能或 SOC 验收。阶段状态仍以 [STATUS.md](STATUS.md) 为准。
