# G03 禁能状态机与本地保护

固件`g03-disabled-r1`仅执行充放电业务的影子状态机，**没有接通实际功率输出的接口**。本版为当前无法配合探头/硬件标定条件下的软件实现与验证；不把它叫作实际开环充放电。

## 状态、时序和方向

`STOPPED → BREAK_WAIT → RELAY_WAIT → CHARGE/DISCHARGE → DECAY_WAIT → STOPPED`，任一活动阶段可进入锁存`FAULT`。

- START只在STOPPED接受；方向1充电、2放电。运行中换向返回BUSY，不排队、不自动重启。
- BREAK_WAIT的期望继电器均断开；等待后仅设置方向继电器的**影子位**，再等待稳定阶段；进入CHARGE/DISCHARGE后影子PWM为1。期间实际TIM、GPIO和继电器始终禁能。
- CCR是人工固定给定，没有PI或跟踪调节。允许停机配置或运行中人工修改；拒绝的值不改变已接受目标。G03只改变影子CCR，不写实际TIM CCR。
- STOP先撤销影子PWM，再等待最小衰减时间且合成电流进入释放范围后打开影子继电器；超时锁存DECAY故障。重复STOP不延长等待。真实故障下触点应如何处置需按实际电路确认，本版不操作触点。
- 请求duration从START接受时起算，包含准备阶段；期限到达按正常STOP处理。短于准备时间的窗口不会进入影子PWM运行。
- CLEAR只回STOPPED，不启动；输入仍异常时下一次START仍拒绝/故障。运行中CLEAR拒绝。参数未知、未选择测试夹具或未初始化时不启动。重复Init不清锁存。

## MCU本地保护与观察边界

`HAL_IncTick()`之后调用`G03_TickIRQ()`，所以运行时限、心跳失联和数据检查由MCU SysTick处理，不等待上位机发STOP或主循环打印完成。主循环命令和报告快照使用短PRIMASK临界区；IRQ不格式化、不打印、不调用阻塞HAL。活动期间每次tick检查实际MOE、CCER、CEN、继电器及PWM GPIO命令位，并调用只含寄存器操作的既有禁能函数。计数和最大tick间隔供诊断。

这不是独立硬件看门狗：CPU停止、全局关中断或SysTick被长期屏蔽时不保证服务时限。原CPU异常处理保持立即禁能；本轮不声称实物栅极或继电器关断时间已测。

`max_tick_gap`使用HAL毫秒计数，不能检测被合并/丢失的SysTick或独立证明墙钟时限；1ms读数只表示观察到的HAL tick差值。严格保护截止期仍需独立计时与实际关断证据。

保护包括：未标定/无效输入、过期数据、每节欠压/过压、正负向电流上限、方向反流、温度越限、互锁冲突、本地心跳超时、衰减超时以及G02外部故障。故障关闭影子输出并锁存；传感器数据不参与连续调节CCR。

## 合成测试夹具不是标定

`g03_port.c:fixture`是独立的软件夹具v1，不是hardware-profile实物参数，也不来自ADC校准。当前G01仍输出未标定的真实原码；G03的合成数据不写入G01记录、不被当作真实电流。

夹具使用20/30/20ms的准备/稳定/最短衰减时间、200ms衰减超时、800ms心跳期限、100ms样本新鲜度、最长10000ms窗口及CCR400—1600。合成电芯范围3000—4200mV、电流±500mA、温度0—45000m°C、继电器释放范围±20mA；正常输入为每节3600mV、25000m°C，运行时±100mA，停机/衰减时0。所有这些数值只为覆盖软件分支，不能用于带载授权。

每份G03响应强制标记`synthetic=1,power_capable=0`。实际位图应为0；主机发现非0、错误身份或标记不符即终止并尝试STOP。原理图/实测未建立前，不提供切换为真实传感器和功率输出的配置开关。

## 串口与重放

沿用`G02,id,op,arg*CRC16\n`请求封装与全局递增id，新op10—19用于G03；响应为`#G03,g03-disabled-r1,...*CRC16`。CRC与重复/过期/冲突处理复用已验证入口。ISR仅排队，主循环执行；最新完全重复请求返回原结果和当前状态，不再次执行，因此重复heartbeat不会续期。STATUS也不续期。

| op | 参数 | 动作 |
|---|---|---|
| 10 | 0 | 状态 |
| 11 / 12 | duration_ms | 充电 / 放电影子START |
| 13 | 0 | 共同STOP：G02先完成清理，G03执行影子衰减停止 |
| 14 | 0 | G03 CLEAR，仅回停机 |
| 15 | 0 | 新请求heartbeat，超时后不可复活 |
| 16 | 0—10 | 选择合成故障场景，0正常 |
| 17 | 0 / 1 | 停机时撤销配置 / 选择夹具v1 |
| 18 | 任意 | 功率请求，始终DISALLOWED |
| 19 | CCR | 影子固定比较值 |

场景1无效、2过期、3越流、4欠压、5过压、6温度、7互锁、8反流、9残余电流、10未标定。响应字段按`scripts/g03/disabled_diagnostics.py:FIELDS`，包含请求结果、实际业务状态、方向、故障、停止原因、配置、影子CCR/继电器/PWM、实际禁能位图、时标、状态转换/启动次数及tick统计。实际位图bit0—5分别为MOE、CCER非零、CEN、充电继电器GPIO、放电继电器GPIO、任一PWM GPIO高；它是寄存器观察，不是引脚/触点测量。

G03活动或锁存故障时拒绝G02采样启动，G02占有ADC/故障时拒绝G03启动。旧G02 STOP也进入共同STOP。G03不占有ADC，G01可继续采集；真实数据与合成诊断有不同帧标识。

## 验证与运行

```powershell
python scripts/g03/run_checks.py --out evidence/runs/<新run>/checks
python scripts/g03/disabled_diagnostics.py --port COM9 --out evidence/runs/<新run>/board
```

原生测试使用生产core、port、UART代码：覆盖两方向、互锁/停止顺序、每节电压、带符号电流、反流/温度、未知配置、清故障、时间回绕、失联、重复心跳、与G02互斥及10000次事件序列不变量。原生HAL/寄存器模型不是电气仿真。主机保存原始串口、请求事件和CSV；实板只证明该镜像在合成输入下的本地逻辑执行。

最终脚本停止并撤销夹具配置；后续START必须显式选择夹具。串口关闭测试是关闭主机句柄，未拔USB。板测不会要求探头或改电池接线。

仍跳过：实际电流/电压/温度标定、驱动/Vgs/死区、继电器实际隔离和释放条件、独立停止期限、真实D→I方向及带载测试。资料冲突、来源和未找到的匹配原理图记录在本轮工作卡的资料审查附件；它们不阻塞禁能软件工作，也不因跳过而变成通过。
