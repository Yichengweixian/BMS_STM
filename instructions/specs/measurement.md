# 测量的分层、换算与标定

## 两条测量路径

慢速监测：电芯端电压 / 电流调理电压 / 温度分压 → ADBMS 内部 ADC → 寄存器数字码 → SPI → MCU。

快速反馈：分流电阻和放大器输出 → STM32 ADC1 → 当前控制周期的电流 → PI → TIM1 PWM。两条电流路径是否共用同一模拟节点，要用原理图和通断测量确认；各自仍需标定。共用前端时，两路一致不等于独立准确。

## 职责表

| 层 | 应完成什么 | 不在这一层实现什么 |
|---|---|---|
| 外设/HAL | 时钟、GPIO、SPI 传输、ADC 触发/DMA、TIM PWM | 电池 SOC、温度传感器模型 |
| 芯片驱动 | 唤醒、转换命令、完成确认、寄存器、PEC、raw 解码、器件规定缩放 | 分流阻值、传感器型号、PI 参数 |
| 板级测量 `measurement` | 通道映射、raw→V、偏置/增益、V→A、分压→Ω→℃、板号/标定版本、有效性 | 设定电流和实验工况 |
| 控制/保护 | 可信且及时的 I 与限值检查、PI、状态机、停止和换向 | SPI 字节拼接、CSV 格式 |
| 应用/记录/估计 | 功率、能量、SOC、HPPC/DST 编排、日志协议 | 在 PC/MCP 中逐个 PWM 周期控制 |

BSP 是组织方式，不是硬性标准：板级测量可以放在 BSP/measurement，也可以独立目录。关键是**器件通用驱动不绑定某块板的系数**。G01 已将当前采集迁至 BSP/adbms_acquisition.c、measurement_core.c 与 measurement.c；main.c 只调度。详细通道、状态和记录方法见 [G01软件采集说明](G01-software.md)。

## 哪些公式要写

1. ADBMS 电芯/AUX 结果：`raw = lo | (hi << 8)`，按对应寄存器定义 `V = raw × 0.0001 V`。不再套 STM32 的 `Vref / 4096`。不是所有 ADBMS 寄存器都表示普通电压，状态、阈值或特殊测量按各自定义处理。依据：[ADI 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/adbms1818.pdf)。
2. STM32 ADC：若确认 12 位、右对齐且没有改变输出尺度的累加/移位，理想量化步长为 `Vref/4096`。工程用 `V=a·code+b` 或 `I=aI·code+bI` 的标定关系；端点拟合有时写 4095，必须明示约定，不在同一链混用。过采样后的最终输出位宽/移位、参考电压、校准流程均须核对。
3. 电流：`Vsense = Vzero + s·G·Rshunt·I`，故 `I=(Vsense−Vzero)/(s·G·Rshunt)`；s 为接线符号。实际可直接拟合 `I=a·raw+b`。芯片不知道外接分流阻值与电流方向，因此这部分由板级软件负责。
4. 温度：只有确认“上拉 R_up 接 Vexc、传感器接地”的拓扑才用 `R=R_up·V/(Vexc−V)`；当前代码示范 PT1000 线性近似 `T≈(R/R0−1)/α`。NTC 需另一套模型；PT1000 宽温区用适合其型号的曲线/查表。系数与适用温区必须记录，不混用教材图示和实装型号。
5. 功率、能量、SOC：在应用层计算。`Pbat=Vpack·Ibat`，充电正、放电负；输出端 `Pout=Vout·Iout`。不同端口的 V、I 不能直接相乘当某端功率。瞬态平均功率为 `mean(v·i)`，未必等于 `mean(v)·mean(i)`。

不必用软件重做 ADBMS 内部 ADC 调制、数字滤波、硬件转换；但仍要选择模式、等待完成、读取并检查质量。芯片内部温度也不能替代电池表面温度。

## 标定流程

先确认量程/电路，再记录 raw 与独立参考，在覆盖工作范围的多个点拟合；独立重采其他点验证；最后检查零点回测、重复性、升降扫和温漂。不要只看 R²。

零点、参考电压、电子标定与整机校准不同：STM32 内部 ADC 自校准不能消除外部放大器/分流/接线误差；一条 ADBMS 电流通道标定也不能替另一条 STM32 通道出证。

正式误差判断应包含参考及方法的不确定度。建议统一用 `|误差| + U95 ≤ 容差` 才判 pass；若 `|误差| − U95 > 容差` 则 fail；覆盖边界时 inconclusive。课程严格“小于”指标应相应使用严格不等式。拟合用数据与独立验证用数据分别列 ID。具体容差见 acceptance，不把分辨率、芯片典型精度或闭环误差当测量精度。


## 当前执行方式：外部参考到串口原码的整链标定

2026-10-31按用户提出的简化方式，优先直接建立物理量与原码的对应，暂停要求用户探测U5细脚。逐个测量分流阻值、放大器增益、内部REF不是整链经验标定的先决条件；内部节点诊断保留在两路不一致、非线性或饱和等异常出现时使用。上文实装料号核对要求针对解释/采用理论系数，不阻止在安全工况下直接进行整链实测。

电流模型分别拟合 I_AFE=a_AFE*raw_AFE+b_AFE、I_MCU=a_MCU*raw_MCU+b_MCU。参考仪表必须测量与板载分流器相同支路的电流；DC-DC输入电源表显电流、负载端电流、设定电流不能直接代替电池侧参考。外部大端子是否处于该支路仍需确认，尚未指定接线。

以确认的零电流点和至少两个不同非零参考点作初步拟合，再取未参与拟合的点独立检查，并回测零点；两点只能确定直线，不能验证线性。充放电分别覆盖实际需要使用的方向和范围，参考量程/环境/采样设置记录随数据保存。未经测量不预填电流值、零点或系数。

固定偏置/比例误差可合并到系数。模型不充分、量程外外推、温漂、自热、饱和、迟滞、噪声及参考仪表误差不能靠一组常数自动消除。板端与参考需要时间配对和稳定工况；只在验证覆盖的电流、温度、供电与采样配置范围内报告误差。

温度也可使用外部独立温度参考作整链标定，但需多个温度点并验证曲线，不将单点平移作为全温区校准。电芯电压已有约3.9V单工况对照，保持既有原始证据，不宣称多点标定已完成。

软件系数的经验拟合不取消功率试验的接线/限值要求。当前仅调整方法，固件仍为r2、uncalibrated-v1；未启用充放电，未写系数。
