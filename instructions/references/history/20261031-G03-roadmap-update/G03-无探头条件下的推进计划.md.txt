# G03：无探头条件下的推进计划

日期：2026-10-31  
性质：探索调试计划，尚未执行的动作不记为完成。  
目标：在现有仪器、接线能力和资料条件下，先解决真实采样问题，再核实受限放电台架，争取取得可重复的单点放电数据，随后扩展局部占空比—电流关系。

## 1. 用户条件与本计划边界

- 用户无法接示波器探头、测量细小引脚或配合硬件精度标定；这些工作暂缓，不反复作为软件推进的前提。
- 已有设备包括三路直流源 UDP3305S、33Ω/25W 标称负载、三节真实电池，以及板载采样、串口和下载调试连接。
- 最近确认的接线是三节真实电池、放电端接33Ω负载、充电端开路。此前三路直流源接电池座的记录属于历史接线；实际实验前需要重新确认。
- 没有找到匹配本板的完整原理图。课程材料、原工程和老师HEX可以作为分析依据，但其示例参数不自动成为本板已验证的参数。
- 软件实现、离线检查和禁能板测继续推进；正式精度标定与探索实验分开处理。
- 本文件只是新建计划，不修改固件、既有阶段状态、实验数据或当前硬件输出状态，也不代替功率实验的具体条件核对。

## 2. 当前应优先解决的问题

截至本计划读取到的 g03-adc-r3 板测记录，功率输出保持关闭，profile 5 的静态稳定尾部均值约为1493.27码；进入扫描采样后记录到1407码，触发了设定窗口。记录中的约−50.3mA来自尚未独立标定的换算，不能解释成已经发生真实放电过流。

这提示采样配置、启动过程、采样节奏或模拟输入稳定性仍需排查，原因尚未确定。该记录也不能直接解释此前1008与2048的差异。

证据：[g03-adc-r3板测记录](../evidence/runs/20261031-G03-real-adc-r3/board-01/result.json)、[故障恢复记录](../evidence/runs/20261031-G03-real-adc-r3/fault-recovery/result.json)。这些是已有记录，不是本计划新执行的测试，也不代表此刻板上状态。

## 3. 执行顺序

### 第一步：解决真实ADC采样的一致性

无需用户接探头。

1. 核对校零、待机、诊断和运行状态下的ADC配置及实际采样节奏，重点检查采样时间、使能/停用过程、通道切换、内部校准、过采样和启动瞬态。
2. 尽量让校零与运行采用相同采样条件；在输出关闭时完成采样稳定性检查，再决定是否允许进入下一状态。
3. 保留完整启动原码，区分稳定前数据和有效测量。启动稳定处理不能变成实际输出期间屏蔽过流保护的窗口。
4. 检查重复启动、持续采样、停止、故障锁存和恢复。不得仅通过放宽阈值、反复追随异常读数重设零点或丢弃异常记录来获得通过结果。
5. 与老师HEX比较ADC初始化、采样时间、校准顺序和零点处理。换算公式已经恢复，后续优先分析采集流程差异，避免重复提取公式而没有新增结论。

完成标准：同一静态工况下读数可重复，校零与运行之间不存在无法解释的明显跳变；真实采样、无效/过期数据处理和本地保护能够稳定运行。比较方法和容差应在对应测试前写明，不根据测试结果倒改。

交付：原因分析或已排除因素、配置对照、原始采样、测试结果和对应固件身份。

### 第二步：明确老师HEX的对照使用方式

1. 优先静态分析其启动路径、PWM/继电器控制、停止操作以及测量输出格式。
2. 如果需要实际运行，先确认其启动不会在未准备的台架上自动开启功率；不能因为它是配套程序就默认只会显示数据。
3. 若能够在功率关闭条件下取得原码、零点和显示电流，则与本程序做同板、同工况对照。
4. 老师程序读数作为软件行为参考。两套程序显示一致只能支持换算一致性，不能单独证明绝对精度，也不能确定开关瞬间的峰值电流。

完成标准：明确其可复用的采样配置和公式、仍有差异的环节，以及是否具备可控运行的条件。启动行为尚未查清时，不直接烧录运行来碰运气。

证据：[HEX公式与受限扫描核对](../evidence/runs/20261031-prebuilt-formula-audit/review.md)。

### 第三步：核实直流源替代电池的单向放电台架

这是候选方案，不是立即改接线或开启输出的操作指令。

拟议工况：移除真实电池，由三路直流源替代电池座输入；放电端保留33Ω负载；充电端保持开路；只研究向负载放电的方向。

执行前核实：

- 对照实机型号及适用手册，确认三路输出的隔离、串联使用条件、极性和原有夹具连接方式。
- 查明约18V板供电是否可能向功率路径供能，以及是否存在其他供能或回灌路径。不能只限制电池座电源就推断整个功率级已经限能。
- 确认电源限流/保护设置和退出方法。电源限流不是开关管瞬态保护，电容储能也不能忽略。
- 普通直流源不能作为已经验证的充电吸收负载；不能仅因充电接口开路就假定所有反向能量路径均已排除。
- 判断电源显示的电流与板载传感器是否位于同一支路。电源读数可先用于变化方向和数量级对照，不直接当成准确的电池电流标定值。

电压、电流上限、起始占空比、单点时限及停止条件由本次台架核对结果确定，当前不填猜测值。课程中的0.90占空比和禁能测试中的50mA阈值均不自动成为真实功率实验参数。

完成标准：能够说明供能路径、受限范围、禁止的方向和停止方法，并形成具体工况表。若无法确定，准确列出需要补充确认的连接或部件；不笼统要求用户完成全部仪器测量。

参考：[UNI-T UDP3305S厂家资料](https://uni-trendus.com/products/udp3305s)。具体通道能力和操作条件以适用实机版本的手册为准。

### 第四步：先验证一个有期限的放电点

仅在前述测量与台架条件满足、实际功率操作已获得明确授权后执行。

1. 第一轮只执行一个固定占空比点，不启动完整扫描，不接入PI。
2. MCU本地执行运行时限、电流窗口、数据有效性和失联等停止逻辑；上位机负责请求、记录和展示，不能作为唯一过流截断路径。
3. 保存启动前、运行中和停止后的原始ADC、标称电流、电池/端口电压、命令占空比、实际CCR、状态及停止原因。
4. 检查启动后电流是否按预期方向变化、停止后是否回落，以及重复试验是否一致。异常退出后不自动重试。
5. 将软件撤销输出与实际电流回落分别记录。串口观察到回落不等于已经测得微秒级关断时间。

完成标准：一个点的输入条件、测量变化和停止过程能够解释且可重复。出现无法解释的跳变、反向电流、饱和或停止后不回落时，保留记录并停止扩展工况。

### 第五步：逐点扩展，并明确成果范围

单点结果可解释后，才逐点扩展局部占空比—电流关系。每个点独立记录输入电压、负载条件和停止结果；出现故障即取消余下工况。

- 占空比是特定输入和负载下的实验条件，不是对所有工况通用的电流标定表。
- 标称换算电流、独立参考读数和最终标定值分别记录；原始ADC及旧失败记录不得覆盖。
- 功率计算只使用同一端口、时间对应的电压和电流，不能混用电池侧电流与负载侧电压。
- 可重复的局部关系可为后续控制方向和算法调试提供依据；未经独立验证的数据不宣称为高精度电流或SOC真值。
- 本路线优先推进单向放电。充电实验另需确认接收能量的对象、充电边界和停止条件，不沿用普通直流源替代电池的工况。

## 4. 当前条件下的交付与暂停边界

| 项目 | 当前推进方式 | 交付/边界 |
|---|---|---|
| ADC一致性、真实输入保护与日志 | 软件分析、实现、离线和禁能板测 | 原始数据、原因分析、稳定性和故障测试 |
| 老师HEX对照 | 先静态分析；运行条件明确后再决定实板对照 | 配置/公式差异，不冒充物理标定 |
| 直流源替代电池的台架 | 核对资料、供能与接线条件 | 可执行工况表，或明确到连接位置的缺项 |
| 单点及局部放电特性 | 测量和台架条件满足后执行 | 真实实验记录、停止行为和局部关系 |
| 波形、死区、峰值和精度标定 | 按用户条件暂缓 | 保留未验证状态，不用软件测试替代 |

如果现有资料和可获得的观察仍不足以确认供能或实际停止路径，仅靠上位机不能消除该硬件未知。届时需要的是针对具体连接/硬件的一次确认或合适的保护夹具；应说明它能解决哪个问题，以及用户不接细小引脚时可采用的替代方式。

## 5. 最近的下一步

优先解决采样切换导致的基线变化，同时核实直流源替代电池的单向放电台架。无需用户立即改变现有接线。不要继续增加与上述问题无关的禁能测试，也不要把正式精度标定当作所有探索工作的统一前置条件。
