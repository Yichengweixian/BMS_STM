# 待确认项与阻塞范围

未知项不意味着所有工作都要暂停。先进行独立的源码、协议、离线处理与禁能测试准备；仅阻塞需要该事实的实验和结论。

| ID | 要确认的事实 | 需要的证据 | 阻塞范围 |
|---|---|---|---|
| H01 | INA199 实装后缀、完整增益、分流阻值 | 原理图/BOM、芯片丝印、已知电流下的实际模拟响应 | 电流绝对换算、相关闭环与SOC结论 |
| H02 | AFE GPIO1 与 MCU PA1 是否同节点、符号与测点位置 | 接线图与实测 | 两路通道对应、Ibat/Iload识别 |
| H03 | PT1000还是NTC、上拉阻值与供电、温度安装点 | 实物型号/电路图/已知温度点 | 温度模型与过温阈值 |
| H04 | ADC实际参考、分辨率、过采样尺度、ADC2的ioc/源码差异 | 配置审查与参考电压实测 | MCU换算、配置可再生成性 |
| H05 | 电芯型号/容量、串联关系、电压电流温度限制 | 制造商规格与实物身份 | 有能量的充放电、容量/锚点实验 |
| H06 | 功率级/负载/供电限制、测量端口、有效死区 | 原理图/器件规格/波形/台架清单 | G03及其后的带载测试 |
| H07 | 正常/故障停止、换向条件、继电器等待、失联策略 | 状态机设计与禁能/受限测试证据 | 远程控制与完整双向验收 |
| H08 | 当前源码对应什么固件；Debug/Release/FSBL实际启动链 | 新构建日志、MAP、下载记录、启动识别 | 固件功能复现、Release交付 |
| H09 | 课程按键步长50/100mA；set/run/bms协议选择 | 明确目标上位机及课程确认、协议契约 | G05一致性验收 |
| H10 | 独立参考仪器与其量程、精度/不确定度、时钟 | 型号/序列号/证书或规格/设置 | 正式标定与保护带判断 |
| H11 | SOC0锚定、Qref条件、效率、标签精度目标 | 容量实验与参考测量方案 | 高可信标签与SOC精度声明 |
| H12 | 最终模型验收目标、泛化对象、数据范围 | 需求与课程评分口径 | G07通过线冻结；可先做原型 |

记录解决方式：在对应工作卡填证据路径、确认人/日期和范围，将实物参数更新到 hardware-profile.json。涉及既有结论时按 WORKFLOW 的影响表复验。
